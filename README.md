# beskrovnyy.pro

Персональный сайт и блог, созданный на [Astro](https://astro.build/).

## Требования

- Node.js — рекомендуется актуальная LTS-версия;
- npm.

## Установка

Перейди в каталог проекта и установи зависимости:

```bash
npm install
```

## Запуск в режиме разработки

Для обычной разработки запусти локальный сервер:

```bash
npm run dev
```

После запуска сайт будет доступен по адресу:

<http://localhost:4321>

Astro автоматически обновляет страницу после изменений в исходных файлах.

В режиме разработки поиск Pagefind не работает, потому что индекс поиска ещё не создан. Этот режим удобен для работы с вёрсткой, страницами и стилями.

## Production-сборка и индекс поиска

Для создания production-сборки выполни:

```bash
npm run build
```

Команда выполняет два шага:

1. Astro собирает сайт в каталог `dist/`;
2. Pagefind анализирует готовые HTML-страницы и создаёт индекс поиска в `dist/pagefind/`.

В результате Pagefind индексирует страницы сайта и создаёт файл:

```text
dist/pagefind/pagefind.js
```

Именно этот файл загружает компонент поиска.

## Просмотр production-сборки

Чтобы посмотреть сайт вместе с работающим поиском, выполни:

```bash
npm run preview
```

Эта команда автоматически собирает сайт, создаёт индекс Pagefind и запускает локальный сервер предварительного просмотра. После запуска открой:

<http://localhost:4321>

Если ты изменил страницы, статьи или другой индексируемый контент, перезапусти `npm run preview`, чтобы Pagefind создал актуальный индекс.

## Какой режим использовать

- `npm run dev` — быстрая разработка с автоматическим обновлением страницы; поиск Pagefind в этом режиме недоступен.
- `npm run build` — собрать сайт и создать индекс Pagefind без запуска сервера.
- `npm run preview` — собрать сайт, создать индекс и открыть production-версию локально; этот режим нужен для проверки поиска.

## Основные команды

| Команда | Назначение |
| --- | --- |
| `npm install` | Установить зависимости |
| `npm run dev` | Запустить сервер разработки |
| `npm run build` | Собрать production-версию сайта |
| `npm run preview` | Просмотреть production-сборку локально |

## Структура проекта

- `src/pages/` — страницы и записи блога;
- `src/assets/` — изображения и другие исходные ресурсы;
- `public/` — статические файлы;
- `astro.config.mjs` — конфигурация Astro;
- `package.json` — зависимости и команды проекта.
